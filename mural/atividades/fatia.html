Monte a fatia da H03.

Uma fatia é uma história de usuário que atravessa todos os arquivos. Em cada arquivo, escolha o pedaço de código que a H03 acrescentou.

H03. Como editor de moda, quero reusar um prompt trocando só os looks, para não reescrever tudo a cada coleção.

A fatia montada: a H03 de ponta a ponta

  1. teste.ts: o teste "reusa trocando os looks" diz o que precisa ser verdade.
  2. modelo.ts: preencherLook troca o {{look}} pela peça.
  3. repositorio.ts: salvarLooks guarda os looks gerados.
  4. servidorMcp.ts: a ferramenta reusar_prompt junta tudo e responde ao Claude.

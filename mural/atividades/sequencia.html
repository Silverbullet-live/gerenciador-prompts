Qual é a ordem do pedido até a confirmação?

Organize as etapas do salvamento de um prompt, do pedido do editor à confirmação do Claude. Arraste os cartões ou use os botões para movê-los.

Ordene a sequência

    Ver por que

    Por que a escolha vem antes da chamada?

    O servidor MCP publica o catálogo de ferramentas disponíveis, com descrições e parâmetros. O Claude usa esse catálogo para escolher a ferramenta; o protocolo MCP transporta a chamada, mas não decide qual ferramenta usar.

    1. O editor faz o pedido ao Claude.
    2. O modelo do Claude interpreta a intenção e escolhe salvar_prompt entre as ferramentas anunciadas pelo servidor MCP.
    3. O app do Claude, como cliente MCP, envia ao servidor a chamada com título, texto, coleção e autor (opcional).
    4. O servidor valida os dados, garante a coleção e grava o prompt.
    5. Depois de salvar, o servidor devolve o resultado e o ID.
    6. Com o resultado, o Claude confirma o salvamento ao editor.

    Bônus · caminho de erro

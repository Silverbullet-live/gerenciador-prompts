# 6. Wireframe do mural (baixa fidelidade)

Feito antes de qualquer código, para validar com o "cliente" o que aparece na tela.

```
+--------------------------------------------------------------+
|  MURAL DE PROMPTS · Análise de Sistemas        ● ao vivo  42 |
|  [Todas] [marketing] [estudo] [código] [criatividade] ...    |
+--------------------------------------------------------------+
|  +----------------------+  +----------------------+          |
|  | CATEGORIA            |  | CATEGORIA            |          |
|  | Título do prompt     |  | Título do prompt     |          |
|  | Trecho do texto do   |  | Trecho do texto do   |          |
|  | prompt, até 4 linhas |  | prompt, até 4 linhas |          |
|  | — apelido · há 1 min |  | — apelido · há 3 min |          |
|  |            [ocultar] |  |            [ocultar] |          |
|  +----------------------+  +----------------------+          |
|  +----------------------+  +----------------------+          |
|  | ...                  |  | ...                  |          |
+--------------------------------------------------------------+
|  Como salvar: diga ao Claude "salva esse prompt na           |
|  categoria ___"                                    [QR code] |
+--------------------------------------------------------------+
```

## Decisões tomadas no wireframe

- Texto grande: o mural é lido de longe, no projetor.
- O cartão mostra só um trecho; o prompt completo se obtém pelo Claude (RF04).
- A instrução de uso fica fixa no rodapé, para quem chega atrasado.

## Atividade

Desenhe no papel a **tela de busca** que o estudante veria se o projeto tivesse um app próprio. Que campos ela tem? O que acontece quando a busca não encontra nada?

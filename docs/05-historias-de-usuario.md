# 5. Histórias de usuário e Kanban

Formato: **Como** [quem], **quero** [o quê], **para** [por quê].

## Backlog da versão 1 (entregue)

| ID | História | Critério de aceite |
|---|---|---|
| H01 | Como estudante, quero salvar um prompt falando com o Claude, para não perdê-lo. | Ao pedir, o Claude confirma e o prompt aparece no mural. |
| H02 | Como estudante, quero buscar prompts por palavra, para reaproveitar o que já funcionou. | A busca devolve título, categoria e trecho do texto. |
| H03 | Como estudante, quero ver as categorias, para saber onde salvar. | A lista mostra nome e quantidade. |
| H04 | Como professor, quero projetar um mural ao vivo, para a turma ver o que está sendo criado. | Novos prompts surgem sem recarregar a página. |
| H05 | Como professor, quero ocultar um prompt do mural, para moderar a projeção. | O cartão some da tela ao clicar em ocultar. |
